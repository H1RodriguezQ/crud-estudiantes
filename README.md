# CRUD de Estudiantes

Aplicación web para registrar, consultar, editar y eliminar estudiantes, hecha con HTML, CSS y JavaScript puro (manipulación del DOM).

**Autor:** Henry Rodríguez Quintero — Lenguajes de Programación, UDES

## Funcionalidades

- **Crear:** formulario con validación y control de documento repetido.
- **Leer:** tabla con todos los estudiantes y buscador por nombre o documento.
- **Actualizar:** el botón *Editar* carga los datos en el formulario para modificarlos.
- **Eliminar:** el botón *Eliminar* borra el registro con confirmación.
- Los datos se guardan en `localStorage`, así que no se pierden al recargar.
